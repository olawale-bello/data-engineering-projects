# BankFraud Detection Pipeline

## Overview
End-to-end cloud data pipeline detecting fraudulent bank transactions built on Microsoft Azure.

## Tech Stack
- Python / SQL / SSMS
- Azure Blob Storage
- Azure Data Factory
- Azure SQL Database
- Power BI

## Key Results
- 2,512 rows processed
- 95 suspicious logins flagged
- 3.78% fraud rate detected
- 7 Power BI visuals

## Pipeline
Raw CSV → SSMS Cleaning → Blob Storage → ADF → Azure SQL → Power BI
